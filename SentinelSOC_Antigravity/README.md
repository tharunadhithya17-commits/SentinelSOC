# SentinelSOC — Mini SOC Dashboard

A beginner-friendly, portfolio-ready Mini SOC web application starter.

## Run
1. Install Node.js 20+.
2. In `backend`: `npm install`, then `npm start`.
3. In `frontend`: `npm install`, then `npm run dev`.
4. Open the URL printed by Vite.

The MVP uses an in-memory backend so it starts without PostgreSQL. The structure is ready for a database migration later.

## Demo
- Login with any username and password of 4+ characters.
- Use **Generate Test Alert** to simulate a safe alert.
- Response actions are SIMULATED only.
